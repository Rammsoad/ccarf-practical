╭───────────────────────────────────────────── 💡 Exam concept ──────────────────────────────────────────────╮
│                                                                                                            │
│  Asking for 'answer only in JSON' in the prompt works almost always… and 'almost' breaks a pipeline:       │
│  sometimes it arrives with ```json, with a sentence before it, or with fields added or missing.            │
│  tool_use with input_schema + forced tool_choice = the JSON is always parseable and follows the schema.    │
│  Schema design: optional fields as nullable (so it doesn't invent), enum with 'otro' + detail.             │
│  Careful: the schema guarantees the SYNTAX, not the SEMANTICS (a total may not add up → demo 4.4).         │
│                                                                                                            │
