Glosario

Los términos de las cinco guías de estudio. Escribe para filtrar; la columna “En el examen” da el nombre en inglés cuando difiere o conviene reconocerlo.

Palabras básicas (si es tu primera vez)
terminalVentana donde escribes comandos (en Mac, la app Terminal; en Windows, PowerShell). Ahí corres python panel.py.
APILa puerta por la que un programa habla con otro. Los labs hablan con Claude por la API de Anthropic.
API keyLa contraseña que deja a los labs usar la API. Vive en tu archivo .env y nunca se comparte.
modeloLa versión de Claude que contesta: Haiku (rápido y barato), Sonnet o Opus (más capaces y más caros).
promptEl texto que le mandas a Claude: instrucciones, preguntas y datos.
system promptInstrucciones fijas que acompañan toda la conversación (el papel, las reglas, el formato).
tokenPedacito de texto (más o menos ¾ de palabra). La API cobra por tokens de entrada y de salida.
toolUna función que Claude puede PEDIR que se ejecute (buscar un pedido, hacer un reembolso). Tu código la ejecuta.
JSONFormato de texto para datos con llaves y comillas, por ejemplo {"pedido": "#12345"}.
schemaLa forma que deben tener unos datos: qué campos hay, de qué tipo y cuáles son obligatorios.
Claude CodeLa herramienta de Anthropic para programar con Claude en la terminal. Las demos del Dominio 3 la usan por dentro.
Agent SDKLibrería para armar agentes con el mismo motor de Claude Code. Viene en el paquete claude-agent-sdk.

loop agénticoEl ciclo del agente: llamas a Claude, ejecutas las tools que pide, le devuelves los resultados y repites hasta que stop_reason sea end_turn.agentic loop
end_turnstop_reason cuando Claude terminó de verdad. Es la señal normal para salir del loop.end turn
tool_useBloque con el que Claude PIDE ejecutar una tool. También es el stop_reason cuando espera ese resultado para seguir.tool use
tool_resultLo que tu código le devuelve a Claude después de ejecutar una tool, dentro de un mensaje con rol user.tool result
max_tokensLímite de tokens de salida. Si se alcanza, la respuesta se corta y stop_reason es max_tokens: NO terminó.max tokens
tokensPedacitos de texto (más o menos ¾ de palabra) con los que se mide lo que entra y sale del modelo, y lo que cuesta.tokens
antipatrónUna forma de hacerlo que parece funcionar pero falla; el examen suele ponerla como respuesta incorrecta.anti-pattern
red de seguridadUn tope de vueltas para que el loop no corra para siempre. Sirve de protección, NO como forma normal de terminar.safety net / max iterations
input_schemaJSON Schema que describe qué parámetros acepta una tool.input schema
system promptInstrucciones generales para Claude (rol, reglas) que van aparte de los mensajes.system prompt
historialLa lista completa de mensajes. La API no recuerda nada: se manda entera en cada llamada.message history
subagenteUn agente al que el coordinator le delega una parte del trabajo; no ve el contexto de los demás.subagent
TDDPrimero escribes la prueba que falla y luego el código que la pasa.test-driven development
CI/CDPruebas y despliegues automáticos cada vez que alguien sube cambios al repo.continuous integration / delivery
pipelineSerie de pasos automáticos (por ejemplo: probar, revisar, desplegar) que corre sin que nadie la vigile.pipeline
jobUn paso del pipeline de CI que corre en una máquina aparte, sin nadie que conteste preguntas.job
PRPropuesta de cambios al código que el equipo revisa antes de unirla (merge).pull request
mergeUnir los cambios de un PR a la rama principal.merge
timeoutLímite de tiempo: si algo no responde antes, se corta y se marca como falla.timeout
frontmatterEl bloque entre --- al inicio de un archivo .md con datos como name, description o paths.frontmatter
SKUEl código único de un producto en el inventario (p. ej. MAN-ROJ-01).stock keeping unit
complianceCumplimiento de leyes y reglas (antilavado, privacidad). Junto con dinero y seguridad, va en código, no en el prompt.compliance
prerequisite gateUn chequeo en tu código que bloquea una tool hasta que se cumpla un requisito (p. ej. verificar al cliente).prerequisite gate
