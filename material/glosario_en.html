Glossary

The terms from the five study guides. Type to filter; the “On the exam” column gives the English name when it differs or is worth recognizing.

Basic words (if it's your first time)
terminalWindow where you type commands (on Mac, the Terminal app; on Windows, PowerShell). That's where you run python panel.py.
APIThe door through which one program talks to another. The labs talk to Claude through the Anthropic API.
API keyThe password that lets the labs use the API. It lives in your .env file and is never shared.
modelThe version of Claude that answers: Haiku (fast and cheap), Sonnet or Opus (more capable and more expensive).
promptThe text you send to Claude: instructions, questions and data.
system promptFixed instructions that go with the whole conversation (the role, the rules, the format).
tokenA little piece of text (roughly ¾ of a word). The API charges for input and output tokens.
toolA function Claude can ASK to have run (look up an order, issue a refund). Your code runs it.
JSONText format for data with braces and quotes, for example {"order": "#12345"}.
schemaThe shape some data must have: which fields there are, of what type, and which are required.
Claude CodeAnthropic's tool for programming with Claude in the terminal. The Domain 3 demos use it under the hood.
Agent SDKLibrary for building agents with the same engine as Claude Code. It comes in the claude-agent-sdk package.
