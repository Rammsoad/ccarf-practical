With Python: the panel

The panel runs the demos with controls, shows each topic's guide next to the lab and compares runs.

  1. Install Python 3.10 or newer.
  2. Open a terminal in this folder (Mac: right-click the folder → New Terminal at Folder; Windows: type powershell in the folder's address bar).
  3. Create the environment: python3 -m venv .venv (on Windows, python -m venv .venv), activate it and run pip install -r requirements.txt.
  4. Copy .env.example as .env (cp .env.example .env; on Windows, copy) and paste your API key. Careful: the file name starts with a dot, it's hidden, and it must not end in .txt.
  5. Run python panel.py: it opens in your browser. Use the ES / EN button to switch languages.

The steps in more detail (and what to do if something fails) are in the README_en.md file in this folder.

How to get your API key

  1. Go to platform.claude.com → Settings → API keys (create an account if you don't have one).
  2. First set a low spending limit (for example 5 USD a month) in the limits or billing section. Running all the demos once costs a few cents.
  3. Click Create key, give it a name (for example labs-ccarf) and, if it lets you, a short expiration date.
  4. Copy the key right then: it's only shown once.
  5. Paste it in your .env file after ANTHROPIC_API_KEY=. Don't paste it in chats, code or screenshots.
  6. When you finish studying, delete it on the same page.

No key? Use the recordings: they cost nothing.
