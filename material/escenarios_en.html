The 6 exam scenarios

According to prep sites, the exam's questions are based on these scenarios and each exam picks 4 of the 6 at random. The names don't come from the official guide; which demos go with each one is our own choice. The demos are listed in the suggested practice order. Click a demo to see its example.

ScenarioWhat gets askedDemos
1. Customer Support Resolution AgentMulti-turn conversation, tools for account lookups, when to escalate to a person, rules that must always hold.1.11.45.21.52.12.25.1
2. Code Generation with Claude CodeCLAUDE.md, skills and slash commands, path rules, plan mode, iterating with examples and tests.3.13.23.33.43.52.5
3. Multi-Agent Research SystemSplitting the work, isolating each subagent, combining results with sources and handling a subagent that fails.1.21.31.62.22.35.35.6
4. Developer Productivity with ClaudeConfiguring Claude Code and MCP, memory across sessions, team vs personal settings, exploring a large codebase.1.72.42.53.15.4
5. Claude Code for CI/CDNon-interactive mode (-p), JSON output with a schema, PR comments, review criteria and independent review.3.64.14.61.64.5
6. Structured Data ExtractionJSON schema, validate and retry, few-shot examples, documents that don't fit and confidence-based human review.4.24.34.44.55.52.3
