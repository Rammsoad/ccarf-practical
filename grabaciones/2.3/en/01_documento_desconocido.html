╭────────────────────── 💡 Concept: tool_choice to order steps and guarantee structure ──────────────────────╮
│                                                                                                            │
│  A document arrives and you don't know whether it's an invoice, a receipt or a contract. You have one      │
│  schema (one tool) per type.                                                                               │
│    1. forced tool (extraer_metadatos) → guarantees that step goes FIRST.                                   │
│    2. any with the 3 extraction tools → Claude MUST pick a schema; it can't answer in text.                │
│    3. auto → with the data in hand, Claude decides: it may answer in text.                                 │
