Con Python: el panel

El panel corre las demos con controles, muestra la guía de cada tema junto al lab y compara corridas.

  1. Instala Python 3.10 o más reciente.
  2. Abre una terminal en esta carpeta (Mac: clic derecho en la carpeta → Nuevo terminal en la carpeta; Windows: escribe powershell en la barra de dirección de la carpeta).
  3. Crea el entorno: python3 -m venv .venv (en Windows, python -m venv .venv), actívalo y corre pip install -r requirements.txt.
  4. Copia .env.example como .env (cp .env.example .env; en Windows, copy) y pega tu API key. Ojo: el archivo empieza con punto, está oculto, y no debe terminar en .txt.
  5. Corre python panel.py: se abre en tu navegador.

Los pasos con más detalle (y qué hacer si algo falla) están en el archivo README.md de esta carpeta.

Cómo sacar tu API key

  1. Entra a platform.claude.com → Settings → API keys (crea tu cuenta si no tienes).
  2. Pon primero un límite de gasto bajo (por ejemplo 5 USD al mes) en la sección de límites o de facturación. Correr todas las demos una vez cuesta centavos.
  3. Da clic en Create key, ponle un nombre (por ejemplo labs-ccarf) y, si te deja, una fecha de vencimiento corta.
  4. Copia la key en ese momento: solo se muestra una vez.
  5. Pégala en tu archivo .env después de ANTHROPIC_API_KEY=. No la pegues en chats, código ni capturas.
  6. Cuando termines de estudiar, bórrala en la misma página.

¿Sin key? Usa las grabaciones: no gastan nada.
