╭───────────────────────────────────────────── 💡 Exam concept ──────────────────────────────────────────────╮
│                                                                                                            │
│  The agentic loop: you send the history → Claude responds → if stop_reason is 'tool_use', YOUR code runs   │
│  the tools and returns tool_result → repeat. You only finish when stop_reason is 'end_turn'.               │
│  Exam anti-pattern: deciding it finished because the response contains text. Claude can write 'Let me      │
│  check…' AND ask for a tool in the same response.                                                          │
│                                                                                                            │
